# DSSI Core A 開発記録 v0.4.4

Sprint 3.3の実地確認から、文章説明とリアルタイム通信観測が同じ表示面を競合していることが分かった。本版では、通信は小型パルス、説明は文章チップ、精査はログという三層へ分離した。

通信文章チップは初期状態で無効とし、保存設定で再度有効化できる。ページ上では基本設定を書き換えずに、パルスの一時停止・消去・表示抑制、文章チップの一時抑制を行える。これによりサイトごとに観測密度を変えつつ、再読み込み後は保存済みの基本設定へ戻る。

パルス保持時間には10秒、30秒、60秒、手動消去まで固定を追加した。通信の時間列を追う目的から、意味上の集約より個別表示を優先し、上限32件で古い表示から除去する。

ログは全時系列の簡易ストリームを初期表示とした。通常ログと診断ログを時系列で読み、必要な一件だけ展開する。従来の全列監査表は詳細表示として維持する。
