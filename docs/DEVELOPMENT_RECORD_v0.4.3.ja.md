# DSSI Core A 開発記録 v0.4.3

## Sprint

Sprint 3.3 — Real-Time Boundary Pulse Visualization

## 判断

Sprint 3.2で通信診断と観測限界を記録できるようになったが、ログを後から読むだけでは、通信がどの操作・時間帯で発生しているかを身体的に学びにくい。そこで、本文やCookie値を追加取得せず、既存の安全な観測メタデータだけを短命な幾何アイコンへ変換する。

## 主な変更

- ログ画面からCoverage Manifestを開けるようにした。
- 観測表へ上下同期型の横スクロールを追加した。
- 文章チップ位置を四方向から八方向へ拡張した。
- Level 2・3・MAXで設定可能な通信パルスを追加した。
- DOM form、fetch/XHR、Beacon/Pingを形で区別した。
- method、Cookie検出状態、別オリジン関係を小型記号へ縮約した。
- 色を警告・安全・注意の意味から切り離した。

## 維持した境界

- request bodyは要求しない。
- Cookie値・Cookie名・Cookie個数は保存しない。
- 入力本文、パスワード、決済番号、クリップボード本文は取得しない。
- 通信の有害性、利用者意図、入力本文含有、サーバー到達を判定しない。
- 保存Cookie監査とページmain world監視はCore Aへ接続しない。

## 既知の保留

- 設定変更を再読み込みなしで全観測器へ反映する仕組み。
- 高通信量SPAでの視覚密度と最大8件上限の実地評価。
- 一般button操作と後続通信の相関。
- 通信パルスの配色・幾何のアクセシビリティ検査。
