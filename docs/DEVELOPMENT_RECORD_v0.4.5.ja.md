# DSSI Core A 開発記録 v0.4.5

## 位置づけ

Sprint 3.3で導入した小型通信パルスの視認性修正である。取得範囲、相関条件、保存スキーマ、権限には変更を加えない。

## 修正理由

従来は外形が通信方式、中央文字がHTTP methodを担っていた。しかし約4〜5mmの表示では内部幾何が潰れやすく、method文字と通信方式の区別も瞬時には読みにくかった。

そこで表示文法を次へ変更した。

```text
外周形 = HTTP method
中央文字 = 通信方式
色 = 観測経路
右上記号 = Cookieヘッダー名の検出状態
左上短線 = 別オリジン
```

## 外周形

- GET: 円
- POST: 四角形
- PUT: ひし形
- PATCH: 六角形
- DELETE: 三角形
- HEAD: カプセル
- OPTIONS: 八角形
- CONNECT: 二重円
- TRACE: 縦長矩形
- DIALOG: 吹き出し外形
- UNKNOWN: 破線円

## 中央文字

- S: 標準form submit
- F: fetch/XHR
- B: Beacon/Ping

## 観測経路色

- DOM観測: 濃いマゼンタ
- webRequest観測: 淡いシアン

この色差は観測経路の識別にのみ使用し、安全、危険、警告、注意を意味しない。methodは外形、通信方式は文字でも保持されるため、色だけに意味を依存しない。

## Cookieヘッダー記号

- ●: 検出
- −: 未検出
- ·: 未観測
- ?: 判定不能

「未検出」はCookie不存在を保証せず、ChromeがDSSIへ提供したヘッダー集合内でCookieヘッダー名を検出しなかったことだけを意味する。

## 非変更事項

- request bodyは要求しない。
- Cookie値は参照、保存、表示しない。
- URL path、query、fragmentは保存しない。
- 通信の安全性、有害性、利用者意図、サーバー到達を判定しない。
