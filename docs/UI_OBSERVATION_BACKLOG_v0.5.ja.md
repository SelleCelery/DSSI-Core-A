# ConnectBits v0.5 UI運用観察票

UIの違和感を逐次修正せず、開発者自身の利用中に蓄積し、一定量ごとに一括修正する。

## 記録項目

| 発見日 | 対象サイト | 画面状態 | 発生条件 | 期待した挙動 | 実際の挙動 | 再現性 | 重大度 | 暫定回避 | 修正候補 | 画像 |
| ------ | ---------- | -------- | -------- | ------------ | ---------- | ------ | ------ | -------- | -------- | ---- |

## 重大度

- P0：ページ利用、入力、送信を壊す。即時修正。
- P1：設定不能、重要UI欠落、誤認を誘発する。次回修正単位で優先。
- P2：読みにくさ、位置、密度、操作感。まとめて改善。

## 既知の観察対象

- SPAでHUDが消失・増殖しないか。
- パルスを消しても操作コンソールが残るか。
- hostname保存状態と一時変更を区別できるか。
- ピン保存・解除・全体設定への返路が明確か。
- 入力欄や重要なサイトUIを覆わないか。
- 英語表示で切断・折返し・幅不足がないか。
- 詳細説明へ必要時に到達でき、通常時は重くないか。
