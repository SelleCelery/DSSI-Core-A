# ConnectBits Public Preview v0.5.0 導入・更新手順

## 1. 配布物

公開プレビューでは、Chrome Web Storeではなく、展開済み拡張機能フォルダーを読み込む方式を採用する。

配布物の標準形は次のいずれかである。

- `ConnectBits-v0.5.0.zip`
- `ConnectBits-v0.5.0-unpacked/`

ZIPは任意の作業用フォルダーへ展開する。`node_modules`、`src`、テスト、開発用設定は実行に不要であり、配布ZIPへ含めない。

## 2. 初回導入

1. ZIPを展開する。
2. ChromeまたはChromium系ブラウザーで `chrome://extensions` を開く。
3. 右上の「デベロッパーモード」を有効にする。
4. 「パッケージ化されていない拡張機能を読み込む」を選ぶ。
5. `manifest.json` が直下にある展開フォルダーを選ぶ。
6. ConnectBitsの導入説明が新しいタブで開く。
7. 観測する情報、観測しない情報、保存、外部通信、判断境界、問い合わせ境界を確認する。
8. 次のいずれかを選ぶ。
   - 説明された範囲で通信観測権限を許可する。
   - 通信観測権限なしで開始する。
9. 既に開いている観測対象ページを再読み込みする。

権限を許可しない選択は正常な利用開始経路である。後から「設置とプライバシー」で変更できる。

## 3. 更新

1. 新しいZIPを別フォルダーへ展開するか、既存の展開フォルダーを置き換える。
2. `chrome://extensions` を開く。
3. ConnectBitsの「再読み込み」を押す。
4. 既に開いている対象ページを `Ctrl+R` 等で再読み込みする。

拡張機能を再読み込みしても、既に開いているタブへ新しいcontent scriptが自動的に再注入されるとは限らない。ページの再読み込みは更新手順の一部である。

## 4. 初回確認

- ツールバーのConnectBitsアイコンからポップアップを開ける。
- 「設置とプライバシー」「観測ログ」「保存済みログを読む」を相互に開ける。
- 粘性レベル2以上またはMAXで通信パルスを表示できる。
- JSONログをエクスポートし、ConnectBits Log Readerで読取専用として再読込できる。
- 通信本文、入力本文、Cookie値がログへ含まれていない。

## 5. アンインストール

`chrome://extensions` でConnectBitsを削除する。削除前にエクスポートしたログファイルは、ブラウザー拡張の管理外にあり、自動では削除されない。

## 6. 既知の制約

- 通信本文は要求・取得しない。
- Cookieヘッダーは存在状態だけを検出し、値を取得しない。
- 未検出はCookieや識別情報の不存在を証明しない。
- WebSocket／WebTransportの確立後メッセージ等は現行観測面の対象外である。
- パルスやログの欠落が、通信不存在を意味するわけではない。
- ログは判断支援用であり、証拠能力、完全性、網羅性を保証しない。
