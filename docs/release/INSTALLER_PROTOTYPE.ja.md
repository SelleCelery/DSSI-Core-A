# ConnectBits v0.5 インストーラー試作仕様

## 位置づけ

v0.5の「インストーラー」は、OSへ常駐プログラムを導入する実行ファイルではない。次の二層から構成する。

1. 再現可能な拡張機能配布物を生成するパッケージ工程。
2. 初回起動時に、権限付与前の判断を支援する導入説明画面。

## パッケージ工程

- `npm run package:release:windows`
- `dist/`を再生成する。
- `release/ConnectBits-v<version>-unpacked/`を生成する。
- 必須ファイルの存在を検査する。
- 展開フォルダー内のSHA-256一覧を生成する。
- PowerShellの`Compress-Archive`で配布ZIPを作る。
- ZIP自身のSHA-256を別ファイルへ出す。

この工程は、Chrome Web Store審査、コード署名、OSインストーラー、更新サーバーを提供しない。

## 導入説明

初回インストール時だけ、service workerの`runtime.onInstalled`から`video-tutorial.html`を開く。チュートリアルの最終場面から`onboarding.html`へ移り、観測方法と任意権限を選ぶ。

チュートリアルの場面位置と完了時刻は`chrome.storage.local`へ保存する。途中離脱後に自動で追跡表示はせず、ポップアップまたは設定画面から利用者が開いたときだけ続きから再開する。完了後の再表示は最初から始める。更新時にはチュートリアルを自動表示しない。

導入説明は次を分離する。

- 開発者が宣言する観測・非観測条件。
- 利用者が読んだことを確認する事項。
- 利用者自身が必要性を判断する事項。
- 開発者が保証しない対応限界。

未提示の将来用途への包括同意は取得しない。通信メタデータ観測の任意`webRequest`権限は、利用者の直接操作によってのみ要求する。説明確認後に、標準設定、ページ上の限定観測のみ、観測を開始しない、の三経路を同格に置く。最初の選択は固定せず、「設定とプライバシー」から変更・撤回できる。

## 返路

導入説明は一度きりの儀式にしない。ポップアップと設定画面からチュートリアルを再開・再表示でき、権限説明はポップアップ、設定とプライバシー、Log Readerから再表示できる。重要な観測目的、保存、外部通信、権限に変更が生じた場合は、onboarding versionを更新し、再確認を求める設計余地を残す。
