DSSI Core A

設定とプライバシー

初期版は入力本文、パスワード、決済番号、クリップボード本文、送信本文を保存しません。 保存対象は設定と、本文を含まない観測メタデータだけです。

ローカル機能

有効化時だけ、ChromeのwebRequest権限とHTTP/HTTPSサイトへの追加アクセスを求めます。 観測対象は信頼済みの内容変更操作から2.5秒以内に始まったfetch/XHR系またはBeacon/Ping系の通信です。 request bodyは要求せず、URLのpath・query・fragmentは保存しません。 request headersはCookieというヘッダー名の検出にだけ一時利用し、値はDSSIの処理で参照・分類・保存・表示しません。

現在の死角

DSSI Core Aは、通信本文、レスポンス、WebSocket確立後のメッセージ、Service Worker内部の因果関係を捕捉しません。 通信メタデータが観測されても、その通信に入力内容が含まれたとは断定しません。 警告が表示されていないことは、安全であることを意味しません。
