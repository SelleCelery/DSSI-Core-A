DSSI Core A

設定とプライバシー

DSSIは入力本文、パスワード、決済番号、クリップボード本文、送信本文を保存しません。 保存対象は設定と、本文を含まない観測メタデータだけです。

ローカル機能

有効化時だけ、ChromeのwebRequest権限とHTTP/HTTPSサイトへの追加アクセスを求めます。 標準モードでは内容変更または標準form送信操作に近接した通信を通常ログへ残します。 MAXでは対象通信のうち相関可能な利用者操作を確認できない通信も診断ログへ記録します。 request bodyは要求せず、URLのpath・query・fragmentは保存しません。 request headersはCookieというヘッダー名の検出にだけ一時利用し、値は保存・表示しません。

MAXは権限や取得内容を増やすモードではありません。現在の観測面で取得できた診断事象と、見ない・見えない領域の説明量を増やします。

表示中の文章チップ右上にある移動ボタンでも、時計回りに位置を変更できます。

通信パルス表示

Level 2・3またはMAXで、標準formのDOM送信境界と、webRequestで観測した通信を小型の幾何アイコンとして一時表示します。 色は観測経路の識別補助であり、安全・危険・注意を示しません。ネットワークパルスはすべて本文未観測です。

□＝DOM form、○＝fetch/XHR、波形＝Beacon/Ping、G/P等＝method、外周の点＝Cookieヘッダー名検出、空点＝未検出、破線点＝未観測・判定不能、左上の短線＝別オリジン。

現在の観測範囲

DSSIが観測するもの、観測後に縮約するもの、主権保全のため接続しないもの、現在の仕組みでは見えないものを分けて表示します。 この一覧自体も完全ではなく、未列挙の未知が残ります。
